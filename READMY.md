# Руководство по запуску тестов

Этот документ содержит инструкции по запуску автоматизированных тестов для API с использованием **Postman** и **SoapUI**.

## Предварительные требования

Перед началом работы убедитесь, что у вас установлено следующее программное обеспечение:

1.  **Postman** (последняя версия)
    *   Скачать можно с [официального сайта](https://www.postman.com/downloads/).
2.  **SoapUI (Open Source)** (последняя версия)
    *   Скачать можно с [официального сайта](https://www.soapui.org/downloads/soapui/).

---

## 1. Запуск тестов в Postman

### Импорт проекта

1.  Откройте Postman.
2.  Нажмите кнопку **Import** (в левом верхнем углу).
3.  В открывшемся окне перейдите на вкладку **Files**.
4.  Нажмите **Upload Files** и выберите файл коллекции:
    `tests/postman/API_Tests.postman_collection.json`
5.  Создайте в окружении строку с ключом URL и значением в формате ссылки на тестовый стенд вида http://api.wishlist.otus.kartushin.su/api
6.  Остальные переменные должны добавиться автоматически скриптами выполняемых в строгом порядке тестов

### Запуск коллекции

#### Способ 1: Запуск через интерфейс Postman (Runner)

1.  Нажмите на кнопку **Runner** в левом верхнем углу (или `Ctrl/Cmd + K`).
2.  В открывшемся окне Runner'а:
    *   Выберите нужную коллекцию (**API_Tests**).
    *   Выберите нужное окружение (**Test Environment**).
    *   Настройте количество итераций и задержки при необходимости.
3.  Нажмите кнопку **Run API_Tests**.
4.  Дождитесь завершения и изучите отчет.

** так же тесты можно запускать по-одному (после хотя бы одного общего прогона) провалившись в сам тест и нажав кнопку SEND **

## 2. Запуск тестов в SoapUI

### Импорт проекта

1. Откройте SoapUI.
2. В главном меню выберите **File -> Import Project**.
3. В поле **Project File** нажмите кнопку обзора (`...`) и укажите путь к файлу:
   `tests/soapui/soapui-project.xml`
4. Нажмите **OK**.

### Настройка окружения

1. Все тесты настроены на хранение переменных в рамках основного проекта
2. необходимо добавить в Custom Properties строку с ключом BASE_URL и значением в формате ссылки на тестовый стенд вида http://api.wishlist.otus.kartushin.su 
3. далее по порядку нужно создать схему переменных, которые будут заполняться по мере выполнения тестов переиспользуемыми значениями:

| Name                | Value                                 |
|---------------------|---------------------------------------|
| savedName           |                                       |
| savedEmail          |                                       |
| savedPassword       |                                       |
| token               |                                       |
| userid              |                                       |
| savedTitle          |                                       |
| savedDescription    |                                       |
| itemId              |                                       |
| randomUUID          |                                       |
| randomColor         |                                       |
| randomAbbreviation  |                                       |
| randomAvatarImage   |                                       |
| randomUrl           |                                       |
| randomInt           |                                       |
| lastId              |                                       |
| lastGiftReserved    |                                       |
| BASE_URL            | http://api.wishlist.otus.kartushin.su |

### Запуск тестов

#### Способ 1: Запуск через графический интерфейс одиночных тестов

1. В левой панели **Navigator** разверните импортированный проект.
2. Найдите тест-сьют (TestSuite), который вы хотите запустить (обычно называется, например, **TestSuite 1**).
3. Правой кнопкой мыши кликните по тест-сьюту и выберите **Launch TestSuite**.
4. В открывшемся окне настройте параметры запуска (можно оставить по умолчанию) и нажмите кнопку **Run**.
5. Наблюдайте за ходом выполнения тестов в нижней панели.

#### Способ 2: Запуск через графический интерфейс одиночных тестов (такое возможно при наличии валидных данных в переменных)
1. В левой панели **Navigator** выберете импортированный проект. 
2. Правой кнопкой мыши кликните по проекту и выберите **Launch TestSuite**.
3. В открывшемся окне настройте параметры запуска (можно оставить по умолчанию) и нажмите кнопку **Run**.
4. Наблюдайте за ходом выполнения тестов в открывшемся окне.
5. Изучите итоговый отчет.
